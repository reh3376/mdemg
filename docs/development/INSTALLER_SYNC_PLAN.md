## Phase 1: Build Infrastructure (goreleaser + Release Pipeline)

**Goal**: Enable Windows and Linux binary distribution from GitHub releases.

### 1.1 Add Windows Builds to goreleaser (CRITICAL)

**Gap**: `.goreleaser.yaml` has zero Windows build targets. The Scoop manifest and PowerShell installer both point to `mdemg_{version}_windows_amd64.zip` on GitHub releases, but no such artifact exists.

**Current state**: Only macOS arm64 and macOS amd64 are built. Linux is commented out (awaiting zig cross-compiler for CGO).

**Fix** — Add Windows builds to `.goreleaser.yaml`:


**Files**: `.goreleaser.yaml`

### 1.2 Add .zip Archive Format for Windows (CRITICAL)

**Gap**: The `archives` section produces only `.tar.gz`. Windows expects `.zip`. The Scoop manifest URL ends in `.zip`. The PowerShell installer downloads `.zip`. The `mdemg upgrade` CLI command constructs `.tar.gz` URLs — wrong on Windows.

**Fix** — Add format override per OS in `.goreleaser.yaml`:

```yaml
archives:
  - id: default
    formats:
      - tar.gz
    format_overrides:
      - goos: windows
        formats:
          - zip
    name_template: "mdemg_{{.Version}}_{{.Os}}_{{.Arch}}"
    files:
      - src: "man/man1/*.1"
        dst: man/man1
        strip_parent: true
      - src: "plugins/uxts-module/manifest.json"
        dst: plugins/uxts-module
        strip_parent: true
```

**Files**: `.goreleaser.yaml`

### 1.3 Fix Stale Cask (v0.2.1 → Remove or Auto-Update) (CRITICAL)

**Gap**: `Casks/mdemg.rb` is frozen at v0.2.1. The Formula (`mdemg.rb`) is at v0.2.11. The Cask references Linux builds that don't exist. The Cask was auto-generated by an older goreleaser config but goreleaser no longer generates it.

**Options**:
- **Option A (Recommended)**: Delete `Casks/mdemg.rb` entirely. Homebrew Formula is the correct installation method. Casks are for GUI apps, not CLI tools.
- **Option B**: Add `casks:` section to `.goreleaser.yaml` to auto-update. But this adds complexity for no benefit — `brew install mdemg` already works via the Formula.

**Decision**: Option A — delete the Cask. The Formula is the canonical install path.

**Files**: `/tmp/homebrew-mdemg/Casks/mdemg.rb` (delete)

### 1.4 Fix `mdemg upgrade` Archive Format Detection (HIGH)

**Gap**: The `mdemg upgrade` CLI command hardcodes `.tar.gz` archive suffix. On Windows, releases are `.zip`. This is a known limitation documented in the beta testing guide.

**Fix** — In `internal/cli/upgrade.go`, detect runtime OS and construct the correct archive URL:

```go
ext := ".tar.gz"
if runtime.GOOS == "windows" {
    ext = ".zip"
}
```

Also fix the extraction logic to handle `.zip` on Windows (use `archive/zip` instead of `compress/gzip` + `archive/tar`).

**Files**: `internal/cli/upgrade.go`

### 4.6 Add Ollama Embedding Dimension Warning (MEDIUM)

**Gap**: Neo4j vector indexes are 3072-dimensional (text-embedding-3-large). The default Ollama model `qwen3-embedding:8b` produces 1536 dimensions. If a user switches from OpenAI to Ollama without recreating the index, all vector queries silently fail.

**Fix**: Add a warning box to both READMEs and the CLI reference:

> **Warning**: If switching embedding providers, ensure dimensions match. OpenAI `text-embedding-3-large` = 3072 dims. Many Ollama models produce fewer. Run `mdemg embeddings check` to verify. If dimensions mismatch, you must recreate the vector index.

**Files**: `README.md` (both repos), `docs/cli-reference.md` (both repos)

- `com.mdemg.neural-sidecar.plist` — sidecar auto-restart

These should be included in Homebrew and installer distributions. `mdemg service install` copies and activates them. Placeholders (`__MDEMG_BIN__`, `__PROJECT_DIR__`, `__HOME__`) are substituted at install time.

## Risk Assessment

| Risk | Impact | Mitigation |
|------|--------|------------|
| Windows CGO build fails | Blocks 1.1 | Pre-verify with `GOOS=windows CGO_ENABLED=0 go build`; if CGO needed, use GitHub Actions Windows runner |
| goreleaser format_overrides syntax | Blocks 1.2 | Test with `goreleaser release --snapshot --clean` before tagging |
| Doc sync introduces errors | Medium | Cross-reference every env var against `config.go` source of truth |
| Scoop hash mismatch after release | Blocks Windows install | Update `bucket/mdemg.json` hash from `checksums.txt` after goreleaser runs |
| Formula auto-update fails | Blocks Mac install | Manual update if goreleaser brew publisher fails |
