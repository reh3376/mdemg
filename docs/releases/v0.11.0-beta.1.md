## What this release is

The first beta candidate for MDEMG — cognitive substrate for AI agents built on Neo4j + TimescaleDB + native LLM. This release consolidates ~140 sprints of hardening, observability improvements, retrieval quality tuning, and fresh-install UX work into a single tagged build for beta testers.

**Install** (macOS):
```bash
brew tap reh3376/mdemg
brew install mdemg
mdemg init --defaults          # works without OPENAI_API_KEY (new in this release)
docker compose up -d
mdemg config validate          # PASSED (or PASSED with next-step hint)
open http://localhost:9999/ui/
```

**Install** (Linux / WSL2):
```bash
curl -fsSL https://raw.githubusercontent.com/reh3376/mdemg/main/scripts/install.sh | bash
mdemg init --defaults
docker compose up -d
```

**Beta test guide:** `packaging/homebrew-mdemg/mdemg_beta_testing.md` (62 tests across 7 tiers)

## Highlights (major arcs shipped since v0.10.1)

### Fresh-install UX (beta-blocker class, 2026-08-05)
- **`mdemg init --defaults` works without `OPENAI_API_KEY`** — falls back to `disabled` mode with a clear 2-option next-steps summary (INIT-DEFAULTS-LOCAL-FIRST-001). No more `config validate → FAILED` on a fresh install.
- **`RSIC_PROTECTED_SPACES` auto-seeded** with the newly-created space (no more scary "destructive actions have no space protection" warning).
- **`mdemg config validate` distinguishes "services not started" from "broken config"** (CONFIG-VALIDATE-TRANSIENT-DISTINGUISH-001) — fresh install reports `PASSED (services not started — run: docker compose up -d)` with exit 0 instead of `FAILED` exit 1.

### Jiminy enforcement arc (2026-08-01 → 2026-08-03)
Jiminy is now an **enforcer** of hard constraints, not merely advisory:
- Strict-by-default (JIMINY-ENFORCE-001)
- Alert-on-block with HIGH severity (JIMINY-ENFORCE-002)
- Time-boxed operator overrides with JSONL + TSDB audit (JIMINY-ENFORCE-003 + ENFORCE-OVERRIDES-TSDB)
- Enforcement-outcome telemetry feeds RSIC (JIMINY-ENFORCE-004)
- Post-hoc missed-violation detector via correction-observe hook (JIMINY-ENFORCE-005)
- UI: Jiminy tab with active overrides + enforcement timeline (ENFORCE-UI-OVERRIDES)
- Auto-execute of `archive_constraint_by_code` with 5-layer strict guards, default-off + dry-run (ENFORCE-AUTO-EXECUTE)

### HITL curation arc (2026-08-04)
Full drain + gate + automation + observability for the human-in-the-loop review platform:
- Invariant-preserving auto-dismiss for contradicted drafts (HITL-AUTO-DISMISS-001)
- Content-quality gate on draft emission (JIMINY-CONTRADICTED-BRIDGE-QUALITY-001)
- Scheduled autograde loop (AUTOGRADE-SCHEDULE-001, default-off)
- Grafana dashboard `mdemg-hitl` with 6 panels (HITL-ANALYTICS-TILE-001)

### Alert-noise reduction arc (2026-07-27 → 2026-08-04)
- Node-drop alert calibration — no more chronic false CRITICALs on operator-authorized recluster (NODE-DROP-CALIBRATION-001)
- SLO alert triage — HTTP 499 for caller-cancel; caller-cancellations no longer inflate `mdemg_http_requests_total` 5xx counts (RETRIEVE-CALLER-CANCEL-001)
- Env-secret scrubber preserves shell env-var references — export-auto no longer blocks on `PGPASSWORD=$TSDB_PASSWORD` false positives (SCRUB-ENV-REF-001)
- Dashboard metric triage — 6/7 operator-flagged "low" metrics were measurement artifacts, fixed with title-embedded design intent (DASHBOARD-METRICS-DEEP-DIVE-001)

## Breaking changes

**None intentional.** This is a beta candidate — no operator-facing API contracts changed. If you find one, please report.

## Known gaps (deferred beyond beta)

- **B4 (operator-side)**: `mdemg upgrade` doesn't auto-upgrade brew-installed binaries when the tap is ahead. Workaround: `brew upgrade mdemg`.
- **Windows native support**: WSL2 only for now. Native Windows is deferred to post-beta.
- **`ADJUST_GUIDANCE_CONFIDENCE` auto-execute**: Deferred (mutation not cleanly reversible without HITL). Insight still fires + surfaces via alert; only manual operator approval mutates.
- **LEVER-C-TIGHTEN-001 T+7d verdict**: In-flight (window closes 2026-08-08). Current defaults (`JIMINY_GUIDANCE_CONSTRAINT_INCLUDE_TOPK=4`, `SIM_FLOOR=0.55`) are shipped; may be recalibrated in v0.11.0 GA based on the verdict.

## Migration notes from v0.10.1

- **TSDB schema**: 22 → 33. Auto-migration on server start (`AUTO_MIGRATE=true` default in Docker); allow ~30s on first boot.
- **Neo4j schema**: V0022 → V0025. Auto-migration on server start.
- **New env vars** (all default-safe): See CHANGELOG.md "Unreleased" section for the full list. Highlights: `JIMINY_STRICT_DEFAULT_ENABLED`, `ENFORCEMENT_AUTO_EXECUTE_ENABLED` (default false + dry-run true), `REVIEW_AUTOGRADE_SCHEDULE_ENABLED` (default false), `RETRIEVE_TIMEOUT_MS` (default 20000).
- **New alert rules** (~10): default-on, opinionated thresholds calibrated from live mdemg-dev traffic. Operator-tunable via env.
