## What this release is

The tester feedback funnel is now fully live. Beta.2 turns v0.11.0-beta.1's static beta plan into a real pipeline: testers can collect a scrubbed diagnostic bundle in one command, submit optional training data with a receipt they can reference for deletion, file structured issue reports via three GitHub templates, and the maintainer sees an auto-labeled + Monday-digest triage view instead of a flat issue list.

Also: caller-cancellation noise on the LLM error-rate dashboard is now filtered end-to-end (E1 → E3 pin test), the reranker A/B verdict is committed as permanent evidence, and the contradicted-bridge sink carries both `obs_id` and `node_id` through approval.

**Install** (macOS):
```bash
brew trust reh3376/mdemg          # first-time only; Homebrew's untrusted-tap policy
brew tap reh3376/mdemg
brew install mdemg
mdemg init --defaults             # works without OPENAI_API_KEY (v0.11.0-beta.1)
docker compose up -d
mdemg config validate             # PASSED (or PASSED with next-step hint)
open http://localhost:9999/ui/
```

**Beta test guide:** `packaging/homebrew-mdemg/mdemg_beta_testing.md` (7 tiers, 62 tests). The old duplicate at `docs/user/mdemg_beta_testing.md` has been removed — canonical is the tap-repo copy referenced from CHANGELOG.

## Highlights (delta since v0.11.0-beta.1)

### Beta feedback pipeline (ARC COMPLETE — 4 sprints)

The tester experience from "install failed" to "maintainer knows about it" is now zero-touch:

- **`mdemg diagnostics collect`** (Sprint A) — one command produces a scrubbed `tar.gz` under `~/.mdemg/diagnostics/` for GitHub issue attachment. Bundles env + config + system info + docker compose ps/logs + server log tail + `/healthz` + metrics snapshot. Every text field passes through `llmclient.ScrubString` (api_key / abs_path / env_secret / email / neo4j_cred; shell env-var references like `$PGPASSWORD` preserved per SCRUB-ENV-REF-001).

- **3 GitHub Issue templates** (Sprint B):
  - `beta-install-report.yml` — mirrors Tier 1 (T1.1–T1.11) as dropdown checkboxes
  - `beta-bug-report.yml` — structured failure report with severity dropdown + reproduction fields
  - `beta-feature-friction.yml` — "worked but confusing" report
  - `config.yml` — chooser page with printable-checklist + full-beta-plan + email links surfaced above the templates
- **`docs/beta/install-checklist.md`** (Sprint B) — printable Tier-1 walkthrough with ✅/❌/⏭ boxes and a "healthy shape" reference.

- **`mdemg beta-share`** (Sprint C) — opt-in training-data submission. Wraps the shipped `tsdb.RunExport` (same privacy scrubber gates the underlying export; PII detected → export blocks, no bundle). Adds a `submission_receipt.json` with a CUIDv2 `submission_id`, 30-day maintainer-side retention notice, and a pre-filled deletion-request email subject line. Interactive opt-in prompt by default; `--yes` bypass for scripts.

- **Auto-triage + weekly digest** (Sprint D):
  - `.github/workflows/beta-triage.yml` — fires on `issues:[opened, edited]` with `beta` label; creates the label palette idempotently (severity:* / os:* / install:*); body-scans template fields; posts one-time welcome comment on `opened`.
  - `.github/workflows/beta-weekly-digest.yml` — Monday 14:00 UTC + `workflow_dispatch`; aggregates open beta issues → single rolling tracker (label `beta-digest`) with snapshot table + top-10 oldest blockers + last-7d activity.
  - `docs/beta/triage-pipeline.md` — maintainer runbook.

### LLM error-rate dashboard honesty (arc extension)

- **`GRAFANA-PANEL-FILTER-001`** — `mdemg-llm-routing.json` "LLM error rate %" panel now applies the same `error != '' AND error NOT LIKE 'caller_canceled:%'` filter that `internal/tsdb/dataset_builder.go::LLMPerformance` uses for the alert rule. Live impact on `retrieval.rerank_cross` (24h): **10.80% → 0.00%** (23 caller_canceled: rows filtered; 0 real errors present).
- New pin test `internal/grafanapin/dashboards_test.go` walks every panel JSON under `deploy/docker/grafana/dashboards/` and fails if a panel reading `llm_interactions.error` in an aggregate lacks the caller-cancel exclusion. Opt-out via inline SQL comment `-- GRAFANA-PANEL-FILTER-001: intentionally unfiltered` (for forensic/debug panels).

### Neural rerank A/B — quality parity, no default flip

- **`NEURAL-RERANK-QUALITY-AB-001`** — data-decided sprint. UVTS 120q A/B on `RERANK_PROVIDER=openai` vs `neural`: neural was 21× faster (122ms vs 2588ms) but Note 02 merge gate (mean ≥ baseline, no per-Q regression > 0.10) failed. **Default stays `openai`**; operators can opt-in to neural via `.env` with `RERANK_PROVIDER=neural`. Verdict artifact committed as permanent evidence at `docs/development/neural-rerank-quality-ab-001/ab_verdict.json`.

### Contradicted-bridge sink hardening

- **`CONTRADICTED-BRIDGE-APPLIED-NODE-ID-001`** — `V0031` migration adds `applied_node_id` column to `contradicted_correction_drafts`; sink now writes BOTH `obs_id` (immutable) AND `node_id` (graph key) on approval. Downstream graph-side consumers no longer need an `obs_id → node_id` join.

### LEVER-C-TIGHTEN-001 T+5d verdict (KEEP-ON)

Verdict artifact `docs/development/lever-c-tighten-001/verdict_t5d.md` committed. Statistical significance z=2.040 (p<0.05), trust EMA recovered above baseline. Defaults confirmed: `JIMINY_GUIDANCE_CONSTRAINT_INCLUDE_TOPK=4`, `SIM_FLOOR=0.55`.
