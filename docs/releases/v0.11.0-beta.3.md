## What this release is

Four days of substrate + platform work focused on **corpus quality** — the binding constraint on Jiminy follow-rate uncovered by JIMINY-FOLLOW-RATE-REMEASURE-001. Also closes several loose threads from the DASHBOARD-TRUTH and HITL-CURATION arcs, plus a routine dependency-bump batch.

Beta testers on beta.2 who upgrade will get honest per-outcome attribution (archived-constraint drag closed), the guidance dataset joining the auto-grade schedule (opt-in), and current dependency versions across CI + go modules.

**Upgrade** (macOS):
```bash
brew upgrade mdemg
mdemg upgrade --docker-only
mdemg config validate
```

**Upgrade** (Linux / WSL2):
```bash
curl -fsSL https://raw.githubusercontent.com/reh3376/mdemg/main/scripts/install.sh | bash
```

**Fresh install:** unchanged from beta.2 — see [`docs/beta/install-checklist.md`](../beta/install-checklist.md).

## Highlights (delta since v0.11.0-beta.2)

### HITL guidance corpus lever (2026-08-08)

- **`HITL-CURATION-003`** — the guidance dataset joins the auto-grade schedule (opt-in via `.env`). New `GuidanceSink.ApplyNonReinforcing` gated to dim==2 only (dims 0/1/3/4 refuse so operator-actionable rows stay visible). New `AutogradePromptHint` teaches outcome_type / guidance_type / rubric-axis semantics. New `SampleStrategy` on `CandidateQuery` — scheduler uses `oldest-ungraded` for starvation-free backfill; interactive CLI defaults to `newest`. Handler queue-drain guard shipped inline: `reviewWriter.Record` now runs only when reinforce=true OR sink handled the grade — response payload gains `grade_recorded: bool`. Opt-in: `REVIEW_AUTOGRADE_SCHEDULE_DATASETS=contradicted_drafts,guidance`.

### Follow-rate measurement + attribution honesty

- **`JIMINY-FOLLOW-RATE-REMEASURE-001`** — passive audit 9 days after the ceiling-remediation arc closed. Headline: 11.62% follow rate (188/1618 actionable, 7d), within 1σ noise of the ≈13% CLAUDE.md recalibrated pin. The ceiling investigation's original 35-50% prediction missed by ≥25pp — its downstream sub-sprint had already recorded this at 12.97%. Corpus quality is now the binding constraint. New arch rule pinned: attribution shipments (assigning codes/IDs/labels retroactively) enable measurement fidelity, they don't move compliance metrics.

- **`JIMINY-ARCHIVED-CODE-FILTER-001`** — investigation of "follow rate trending downward" caught a real bug: `loadSpaceConstraintCodes` loaded all constraint codes WITHOUT filtering `is_archived`, letting the fallback keyword matcher assign archived constraint codes to fresh guidance items. Live stats on mdemg-dev: 128 of 261 constraint-code-bearing nodes were archived (~49% of the pool). Fix filters `NOT coalesce(*.is_archived, false)` across 7 sibling Cypher READ sites (5 needed the fix; 3 already had it via vector-index paths). New pin test `TestConstraintCodeCypher_AllPathsFilterArchived` regresses on any future MATCH lacking the filter. Sprint-shape lesson pinned: hand-audit missed 4 of 5 siblings; write the pin test FIRST for property-filter class of fixes.

### Dashboard truth arc closeout

- **`METRICS-DEPRECATE-JIMINY-CONSTRAINT-EFF-001`** — retire the lifetime-cumulative `mdemg_jiminy_constraint_effectiveness` gauge (DASHBOARD-TRUTH-001 flagged the honesty issue; DASHBOARD-TRUTH-003 E4 deleted the dishonest panel). Zero-reader after E4 → per DORMANT-METRICS-CLEANUP-001 discipline, no dashboards means no writer. Removed field decl + factory + 2 caller sites + dashboard SQL fragment + inventory entry. `stats.ConstraintEffRate` field itself preserved (used by J17 protocol sub-score + RSIC report).

- **Windows native support**: WSL2 only.
- **`ADJUST_GUIDANCE_CONFIDENCE` auto-execute**: deferred (mutation not cleanly reversible without HITL).
